🌟 HNG Stage 0 Task — Profile Card Component

This project is a responsive and accessible profile card built with vanilla HTML, CSS, and JavaScript. 
It displays user information including a name, biography, avatar, hobbies, dislikes, and social media links — along with a real-time clock showing the current time in milliseconds.

🚀 Features

✅ Responsive Design — Looks great on mobile, tablet, and desktop  
♿ Accessible — Uses semantic HTML and ARIA attributes  
⏰ Dynamic Clock — Updates the current time every 100 milliseconds  
🖼️ Avatar Upload — Upload and preview your own profile image  
🌙 Dark Mode Ready — Adapts to your system’s dark/light preference  

🛠️ Tech Stack

HTML5 — Structure & semantics  
CSS3 — Styling with Flexbox & Grid  
Vanilla JavaScript — Dynamic interactivity  

💻 Getting Started

Follow these steps to run the project locally:

1️⃣ Prerequisites  
A modern web browser (Chrome, Edge, Firefox, Safari, etc.)

2️⃣ Installation
- Clone this repository:
  git clone https://github.com/00Yila/profile-card-component.git
- Navigate into the directory:
  cd profile-card

3️⃣ Run  
Simply open the index.html file in your browser.

🧩 Task Requirements

This project was built to meet the following specifications:

🧱 Structure & Semantics  
Uses semantic HTML tags: <article>, <header>, <figure>, <nav>, <section>

🧪 Testing Attributes  
All key elements include data-testid attributes:
- Profile Card — data-testid="test-profile-card"
- User Name — data-testid="test-user-name"
- Biography — data-testid="test-user-bio"
- Current Time — data-testid="test-user-time"
- Avatar — data-testid="test-user-avatar"
- Social Links — data-testid="test-user-social-links"
- Hobbies — data-testid="test-user-hobbies"
- Dislikes — data-testid="test-user-dislikes"

⚙️ Behavior  
- Real-time milliseconds clock updates continuously  
- Avatar image is changeable via file upload  
- Social links open in new tabs with rel="noopener noreferrer"  
- Fully keyboard-navigable with visible focus states  

📱 Responsiveness  
Designed using CSS Flexbox and Grid, ensuring a smooth layout across all screen sizes.
